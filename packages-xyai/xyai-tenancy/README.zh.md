# @xyai/dsh-tenancy

[English](README.md) | 中文

## 概述

Host 注册经过验证的 `xyai-tenancy` 设置命名空间——租户名称、套餐、座席、授权密钥、到期日与逗号分隔的授权能力;浏览器半在同一作用域上渲染「租户与许可」设置页:每次保存一次原子变更、可写门控、可恢复默认。功能开关从 Host 设置库读取该文档;浏览器半不增加模型上下文或工具。

## 模型体验

无。本包只注册浏览器侧设置页，不增加模型上下文或工具。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与延期工作

- **单部署文档**：取值描述当前部署的租户与许可;租户隔离与服务端许可校验属于商业化基础设施阶段。
- **未发布 `./invariant`**：slot 注册由 UI 插槽注册表观测，本包没有可独立发生偏离的运行时关系。
