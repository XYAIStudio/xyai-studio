# @xyai/dsh-knowledge-app

English | [中文](README.zh.md)

This bundle inserts `@xyai/dsh-knowledge` over the DSH Web application. The `xyai-knowledge` profile uses it to assemble and verify the knowledge module independently, while the complete `xyai` profile continues to receive the same plugin from `@xyai/dsh-xyai-app`.

Launch through the supported DSH profile entrypoint:

```sh
dsh --profile xyai-knowledge
```
