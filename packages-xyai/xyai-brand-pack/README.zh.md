# @xyai/dsh-brand-pack

[English](README.md) | 中文

## 概述

Host 注册经过验证的 `xyai-brand` 设置命名空间：品牌名、标识文字、强调色、正文色、渐变起止色、愿景文案、逗号分隔的生态站点、ICP 备案号，以及以 data URL 存储、上限约 60KB 的图片 Logo。浏览器半以一次原子变更编辑全部字段，将保存值投影到侧栏与首屏 hero 品牌插槽，并对两个 brand-primary token 应用可释放的主题覆盖层；配置了正文色时额外覆盖 label-primary token。配置了 ICP 备案号时，它在 hero 品牌标记下方与品牌预览中渲染为可点击的工信部备案查询链接。重置移除用户覆盖，保存失败保留草稿。

## 模型体验

无。本包只注册浏览器侧品牌设置与主题插槽，不增加模型上下文或工具。

#### KV Cache 影响

无；本包既不组装也不发送提供方请求。

## 已知限制与延期工作

- **需要可写设置**：连接没有可写的 Host 设置作用域时禁用品牌编辑。
- **未提供租户级品牌**：按租户隔离的品牌配置属于 `xyai-tenancy` 边界。
- **正文色为单值**：配置后同时应用于明/暗主题；留空则跟随主题默认。
- **未发布 `./invariant`**：插槽归属与设置验证由对应的 DSH 服务负责，本包没有可独立发生偏离的运行时观测关系。
