# XYAI Studio 0.5 安装说明

## 安装

运行 `XYAI-Studio-0.5.0-Setup-x64.exe`，按向导安装。

## 使用

1. 打开「XYAI Studio」
2. 在输入框输入消息，点「发送」
3. 若本机已登录 Codex，将走真实模型；否则自动 MOCK 回退（界面状态栏可见）

## 环境变量（可选）

- `XYAI_CODEX_MOCK=1` — 强制 MOCK
- `XYAI_CODEX_BIN` — 指定 `codex.exe` 路径

## 范围

本版为 0.5 内测：Electron 对话窗 + Codex。不含 AI 员工、不含 OpenXYOS 业务全量。
