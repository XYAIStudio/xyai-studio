# XYAI Studio v0.3 更新日志

发布日期：2026-09-02  
适用安装包：`XYAI Studio Setup 0.3.0.exe`

## 本次重点

v0.3 将 XYAI Studio 的桌面端工作流集中到统一的 XYAI Founders 界面：用户可从工作台发起对话、管理本机知识库、按硬件选择本地模型，并在设置中查看故障日志分析。

## 新增与优化

### 工作台与导航

- 左侧栏新增“知识库”“智能体定制”“模型广场”入口。
- 工作台增加对话输入框；发送内容会自动创建或进入对话会话。
- 插件发布页不再显示全局“项目（可选）”卡片，减少发布流程干扰。
- 登录/注册与系统设置使用左侧账户区域展开，避免覆盖对话区域。

### 本地模型与模型广场

- 自动读取本机 CPU、内存和已识别 GPU 信息，为用户展示匹配的模型推荐。
- 模型由用户自主选择后才可一键下载、部署和注册；系统不会自动安装模型或代为配置云端模型。
- 调用本地模型时，在模型选择区域显示本机内存及显存使用情况。
- 对本地模型不可用、显存/内存不足、Ollama 服务未启动等情况提供明确的处理提示。

### 知识库

- 支持挂接本机目录并递归盘点子目录及可解析文档。
- 自动跳过 Windows 系统保护目录、回收站、无权限路径、符号链接、超限文件和不支持的文件类型，避免 `EPERM` / `EACCES` 阻断整盘挂接。
- 已挂接目录改为可展开的层级树；点击文件夹后显示其下级目录与文件。
- 目录列表仅显示可解析文件；无法解析或被跳过的文件不再混入用户可见清单。
- 后台解析展示排队、进度、完成、失败与警告状态；支持“停止解析”。停止会在当前文件完成后安全生效，不写入半成品索引。
- 索引取消操作写入本机知识库审计记录；已成功完成的历史索引保持不变。
- 解析完成后支持文件预览、文本检索、蒸馏记忆与引用溯源。

### 设置与故障处理

- 设置中新增“故障日志分析”。
- 对权限拒绝、资源不足、本地模型/推理后端不可用和常见 OpenRouter 调用问题给出针对性说明。
- 诊断报告不包含对话提示词或密钥；复制前会进行凭据脱敏。

### 品牌与文案

- 内测声明调整为“XYAI Studio 与 DSH 的联合内测”。
- 关于我们页面移除备案中的旧文案。

## 已知限制

- 当前 Windows 安装包未进行数字签名；首次安装时 Windows 可能显示发布者提示。
- 本地模型推荐基于当前可识别硬件与保守资源估算；实际速度和可用显存会随驱动、其他程序和模型量化版本变化。
- 云端模型的账号、密钥、套餐和连接方式由用户按自身需求配置。
